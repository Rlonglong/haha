## 1. `TABLE_CSV_MAPPING`(檔案線)

檔案:`dagster_code/table_mapping.py`

> 📘 這裡是**快查表**。想知道某個設定「為什麼要這樣設計」「不填會怎樣」「有什麼連帶影響」,
> 請看 **[附錄 A · table_mapping 設定詳解](../附錄/A_table_mapping設定詳解.md)**。

### 1-0 FTP 下載

| 鍵 | 型別 | 預設 | 必填 | 說明 |
|---|---|---|---|---|
| `use_ftp_fetch` | bool | `False` | 否 | 是否建立 `*_fetch_ftp` 節點自動下載 |
| `ftp_remote_template` | str | 無 | 條件 | 完整遠端路徑模板,`{date}` 會被替換。與下面兩個**互斥** |
| `ftp_remote_dir` | str | 無 | 條件 | 遠端目錄。遠端檔名帶時間戳時用這個模式 |
| `ftp_remote_filename_prefix` | str | 無 | 條件 | 遠端檔名前綴,`{date}` 會被替換。與 `ftp_remote_dir` **必須成對** |
| `use_ftp_zip` | bool | `False` | 否 | 來源是加密 zip;同時讓 sensor 改監控 `.zip` |
| `zip_inner_filename` | str | `None` | 否 | zip 內要抽出的檔名;不給就取第一個檔 |
| `expected_part_count` | int | `1` | 否 | 大於 1 代表遠端拆成多檔,下載後合併 |
| `staging_subfolder` | str | 表名 | 否 | VM1 家目錄下的暫存子資料夾(**明文只落在這裡**) |
| `archive_dir` | str | 無 | **開 FTP 時必填** | 封存目錄 |

### 1-1 路徑與基礎

| 鍵 | 型別 | 預設 | 必填 | 說明 |
|---|---|---|---|---|
| `input_folder` | str | FTP 模式下為表名 | **非 FTP 模式必填** | 原始檔目錄;加密輸出也固定寫回這裡 |
| `output_folder` | str | 同 `input_folder` | 否 | 清洗輸出目錄 |
| `error_log_dir` | str | `<output_folder>/bcp_error_logs` | 否 | BCP 錯誤 log 目錄 |
| `template` | str | 無 | **是** | 本地檔名模板,必須含 `{date}` |
| `freq` | `"daily"` \| `"monthly"` | 無 | **是** | 決定分區、日期格式、群組、由哪支 sensor 管。⚠️ 不填 = 月檔 + `{date}` 變 6 碼 + 兩支 sensor 都不管它 |
| `delimiter` | str | `","` | 建議明確填 | CSV 分隔符。**逗號與 `\|` 都被使用者輸入打敗過**,現用罕見符號(如 `〨`)。見[附錄 A](../附錄/A_table_mapping設定詳解.md#delimiter) |
| `use_data_rule` | bool | `False` | 否 | 建立 `*_named` 節點套檔規 |
| `data_rule_sheet` | str | 表名 | 否 | 檔規 sheet 名與表名不同時指定 |
| `manual_only` | bool | `False` | 否 | 完全不自動觸發,只能手動 materialize |

### 1-2 處理邏輯

| 鍵 | 型別 | 預設 | 必填 | 說明 |
|---|---|---|---|---|
| `has_clean_func` | bool | `False` | 否 | 建立 `*_clean` 節點。**VM1 的 `CLEAN_FUNC_MAP` 必須有對應註冊** |

### 1-3 容錯

|---|---|---|---|---|
| `retries` | int | `0` | 否 | 資產層重試次數。**`0` = 完全不重試** |
| `retry_delay_sec` | int | `60` | 否 | 重試間隔秒數 |

### 1-4 BCP

| 鍵 | 型別 | 預設 | 必填 | 說明 |
|---|---|---|---|---|
| `bcp_target` | str | 表名 | 否 | BCP 目標表或 View |

### 1-5 索引

| 鍵 | 型別 | 預設 | 必填 | 說明 |
|---|---|---|---|---|
| `use_index` | bool | `False` | 否 | BCP 前 DISABLE、BCP 後 REBUILD(FILLFACTOR 100) |
| `index_name` | str | `IX_<表名>` | 否 | 索引名稱 |

### 1-6 分區

| 鍵 | 型別 | 預設 | 必填 | 說明 |
|---|---|---|---|---|
| `use_partition` | bool | `False` | 否 | 啟用分區自動維護 |

## 2. `SQL_TO_CSV_MAPPING`(匯出線)

檔案:`dagster_code/table_mapping.py`(下半部)

| 鍵 | 型別 | 預設 | 必填 | 說明 |
|---|---|---|---|---|
| `source_table` | str | 無 | 與 `source_sql` 二擇一 | **資料庫實體表名(alias)** |
| `date_column` | str | 無 | 用 `source_table` 時需要 | 日期篩選欄位 |

| `output_folder` | str | 無 | 否 | VM1 輸出目錄。**同時給 `ftp_remote_path` 時會被忽略** |
| `template` | str | 無 | **是** | 輸出檔名模板,含 `{date}` |
| `ftp_remote_path` | str | 無 | 否 | 送 FTP 的路徑;結尾 `/` 會自動接檔名。**設了就不落地** |
| `keep_local_copy` | bool | `False` | 否 | **測試用**:同時給 FTP 與本機時仍要落地。會在 log 發警告 |
| `one_more_day_flg` | bool | `False` | 否 | 檔名日期 +1 天(查詢區間不變) |
| `freq` | str | `"daily"` | 否 | 決定分區與日期格式 |
| `delimiter` | str | `","` | 否 | 分隔符 |
| `encoding` | str | `"utf-8-sig"` | 否 | 輸出編碼(`-sig` 是給 Excel 的 BOM) |
| `retries` / `retry_delay_sec` | int | `0` / `60` | 否 | 重試設定 |
| `depends_on_dbt_model` | str \| list[str] | 無 | 否 | 上游 dbt 模型的**檔名**。決定何時自動觸發 |
| `decrypt_fields` | list[str] | `[]` | 否 | 匯出前還原成明文的欄位 |

## 3. `DB_SYNC_MAPPING`(DB 同步線)

檔案:`dagster_code/db_sync/config.py`

| 鍵 | 型別 | 預設 | 必填 | 說明 |
|---|---|---|---|---|
| `freq` | `"daily"` \| `"monthly"` | 無 | **是** | 分區與批次分組長度(8 / 6 碼) |
| `source_db` | str | 無 | **是** | 來源資料庫名 |
| `source_table` | str | 無 | **是** | 來源表 `schema.table` |
| `bcp_target` | str | key 名 | 否 | 我方目標表 |
| `decrypt_fields` | list[str] | `[]` | 否 | 來源端要解密的欄位 |
| `encrypt_fields` | list[str] | `[]` | 否 | 入我方 DB 前要加密的欄位 |
| `decrypt_key_env` | str | `"SOURCE_DECRYPT_KEY"` | 否 | VM1 `.env` 的金鑰變數名 |
| `sensor_watch_col` | str | `"NOTIFY_DATE"` | 否 | sensor 分批次的欄位 |
| `notify_date_col` | str | 同 `sensor_watch_col` | 否 | 撈資料時 WHERE 的欄位 |
| `delimiter` | str | `"\|"` | 否 | 中繼 CSV 分隔符 |
| `retries` / `retry_delay_sec` | int | `0` / `60` | 否 | 重試設定 |

模組層常數:

| 常數 | 值 | 意義 |
|---|---|---|
| `DB_SYNC_STABLE_SECONDS` | `300` | 筆數要穩定多久才算到齊 |

## 9. 白名單驗證規則

設定值不合法時,**code location 載入階段就會失敗**(刻意的早失敗設計)。

| 驗證函式 | 規則 | 套用在 |
|---|---|---|
| `validate_sql_identifier` | `^[A-Za-z_][A-Za-z0-9_]{0,127}$` | 表名、`bcp_target`、`index_name`、`partition_function`、`archive_table`、db_sync 的所有欄位名 |
| `validate_path_component` | `^[A-Za-z0-9_-]{1,128}$` | `staging_subfolder`、`ftp_remote_filename_prefix`(去掉 `{date}` 後) |

**為什麼要這樣**:這些值無法用 SQL bind parameter 帶入,只能字串拼接,
白名單是唯一能擋 SQL 注入與路徑穿越的地方。**不要為了讓某個名字通過而放寬規則。**
