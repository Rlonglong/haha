## 一句話版本的系統說明

> 檔案(或來源資料庫)有新資料 → **VM4 的 Dagster** 偵測到 → 透過 SSH 叫 **VM1** 去下載、解密、清洗、灌進 SQL Server → 資料進來後自動觸發 **dbt** 跑出詐欺偵測名單 → 名單再匯出成 CSV 送出去。
>
> **VM4 只負責指揮,不碰資料;VM1 負責幹活,碰得到資料。**
